Strict No-JIT Architecture

Fully compliant with App Store Guidelines 2.5.2 & 4.7. High-performance direct-threaded cached IR block interpreter powered by guaranteed tail-call dispatch ([[clang::musttail]]) and ARM64 NEON SIMD lowering.

🎨

Direct Apple Metal 3/4

Zero MoltenVK or Vulkan translation overhead. Direct rasterization via MTLRenderCommandEncoder, TBDR in-tile programmable blending for GS destination alpha test, and GPU compute eDRAM swizzle blitting.

🚀

Mobile Speedhack Engine

Adaptive Emotion Engine underclocking (50% to 100% target clock), Multi-Threaded microVU1 (MTVU) core offloading, idle loop suppression, and instant fast CDVD sector caching.

🎮

DualShock 2 & MFi Input

Comprehensive controller support via Apple GameController framework for Sony DualSense, DualShock 4, Xbox Wireless, and Backbone One, paired with a customizable haptic touch overlay.

💾

Full Game & Memory Suite

10-slot instant quick save/load states with preview thumbnails, standard 8 MB virtual memory cards (.ps2), automatic 16:9 widescreen and 60 FPS PNACH patch injection.

📦

Extensive Disc Support

High-speed loading of uncompressed ISO, BIN, CSO, and modern compressed CHD disc formats directly from the iOS Files app or external USB storage.
